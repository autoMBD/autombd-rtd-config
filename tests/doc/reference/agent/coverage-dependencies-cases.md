| CD-001 | R01, R03, R05, R07 | 多个实现、测试或审阅路径由共享检查覆盖，未声明虚构直接边；覆盖图在不同受支持版本及有效路径上变化。 | 共享覆盖可以通过结构校验；不产生、反转或补齐依赖边。 |
| CD-002 | R01, R03 | 真实直接关系构成多级链，端点由不同所选检查覆盖。 | 各真实边分别保留；不强制同一检查或跨级捷径。 |
| CD-003 | R02, R05, R08 | 真实源、分离的 Test/Implementation 变更和完整局部交接链符合契约。 | 公共入口和 CLI 检查通过；提交和源内容不被校验修改。 |
| CD-004 | R03 | 同一有向路径对重复出现，reason 相同或不同。 | 重复声明被依赖规则拒绝，不能由集合去重掩盖。 |
| CD-005 | R03 | 声明边的源端或目标端缺少所选覆盖，或端点的检查仅被排除。 | 声明依赖的覆盖不完整，结构校验拒绝。 |
| CD-006 | R02 | 实际变更清单遗漏、添加、重复路径或分配错误所有者。 | 保持完整精确清单并拒绝错误映射。 |
| CD-007 | R02, R05 | 路径映射引用非法检查/需求、错误覆盖路径、不被该检查覆盖的需求或空映射。 | 通过既有覆盖或 schema 规则拒绝；额外依赖不能代替覆盖。 |
| CD-008 | R02, R05 | 两个源 lane 修改同一路径。 | 所有权重叠被拒绝。 |
| CD-009 | R05, R07 | 摘要、Governor、HEAD、Test/Implementation tip、manifest 或关闭字段形状与真实源不一致。 | 既有身份、引用及格式拒绝行为保留。 |
| CD-010 | R04 | 省略已知真实边，虚构已覆盖边或描述不实 reason，但声明图在结构上完整。 | 结构 CHECKED 不证明语义；精确源对照显示该材料需要 Orchestrator 拒绝语义接收。 |
| CD-011 | R06 | 元数据变更试图修改冻结检查 ID、类型、命令、需求、覆盖、排除范围或预验证模式。 | 保持冻结语义并拒绝变更；Candidate 也拒绝替换已批准的 Impact Set。 |
| CD-012 | R06 | 描述性端点笔误修复绑定真实 blob，或逐边审计、端点绑定不完整。 | 完整真实审计可接受；缺失审计/绑定被拒绝，不改源或批准。 |
| CD-013 | R06 | 非用例支持新增文件导致覆盖调整，具备或缺少真实源变化绑定。 | 只有真实源变化及既有修复约束满足时允许支持覆盖调整；陈旧执行证据仍不得复用。 |
| CD-014 | R04, R07, R08 | 公开说明区分声明图、源码监督及校验器升级；代码/协议变更在窄范围内。 | 保留公开字段、版本和来源边界；禁止越界文件/规则变化；文字真实性仍由源码审阅负责。 |
| CD-015 | R08 | 完整公开需求、独立用例和共享索引作为同一 Test 交付。 | R01–R08 正文及来源完整，需求/用例配对可审阅，自动化映射单独留证。 |
