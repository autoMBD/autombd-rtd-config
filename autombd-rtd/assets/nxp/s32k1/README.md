[`../s32k3/`](../s32k3/) layout: `assets/nxp/<family>/<module>/` (per-module
schema/constraint/dependency caches derived from each `<Module>.xdm`, plus

family is populated when S32K1 support is scheduled on the
[roadmap](../../../../docs/roadmaps/rtd-config-roadmap.md); no runtime code
reads this directory until then.
